# Changes

## 1.0.0

First release.

- Conversations as JSON Lines with user, bot and agent messages, optional topic and handover flag.
- Containment, handovers, requests for a person, fallback answers and turns per conversation.
- The questions behind handovers and fallbacks, masked and grouped; handovers by topic.
- Custom phrase lists for fallbacks and requests for a person; `--min-containment` as a gate.
- Reports as text, Markdown and JSON.
- Release packages come with a CycloneDX SBOM, SHA-256 checksums and a build provenance attestation.
